## Raw Requirements
- 我需要一个工具可以快如部署我的nuxt项目到我自己的服务器。
- 你可以参考我现有的项目的工作流程，作为基础。
- 我需要这个工具尽可能的胜任基于nuxt项目不同情况，比如SSR/SSG，或者其他情况。
- 我需要他能作为一个依赖安装，并且最好能无感的配置，而不是增加一个deploy.config.js这样的文件。
- 需要你决策他是否应该作为一个全局依赖会更好些，然后通过配置文件来管理当前项目的运行内容
- 支持全局配置和 profile
- 部署在服务器端解压后的dist目录需要事先找到正确的nginx所有者权限，并赋予用户和组权限
- 我需要部署的主流程是：
  - 选择发布的版本，选项，参数。
  - 本地 build -> 打包 .output -> 上传 dist.tar.gz -> 服务器解压到新目录 -> 切换当前版本 -> pm2/nginx reload/restart
